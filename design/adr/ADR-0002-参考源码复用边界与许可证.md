# ADR-0002：参考源码复用边界与许可证

- 状态：待用户确认（本 ADR 的最终结论依赖项目许可证选择）
- 日期：2026-10-14
- 决策者：实现方提出，用户裁定

## 背景

工作区提供了 5 份参考源码快照。审计得到的许可事实：

| 项目 | 许可证事实 | 源码定位 |
|---|---|---|
| Clash Verge Rev | `GPL-3.0-only` | `src/references/clash-verge-rev-dev/package.json`（`"license": "GPL-3.0-only"`） |
| ClashMetaForAndroid | 仓库根含 `LICENSE` 与 `NOTICE`，本轮未逐条比对其具体条款 | `src/references/ClashMetaForAndroid-main/LICENSE`、`NOTICE` |
| sing-box | 上游声明 GPLv3-or-later 且带命名/关联条件（原设计包 S10 记录） | 待固定版本后复核 |
| Xray-core | 仓库根含 `LICENSE`，本轮未读 | `src/references/Xray-core-main/LICENSE` |
| Xboard | 仓库根含 `LICENSE`，本轮未读 | `src/references/Xboard-master/LICENSE` |

GPL 系代码具有传染性：复制其源码进本项目，会使本项目整体需以 GPL 兼容方式分发。

## 决策

1. **只参考设计思路，不复制代码**：桌面 UI 与 Android UI 均独立实现。允许参考的范围是信息架构、交互流程、状态机设计、模块划分；禁止直接复制源码、资源文件、图标与文案。
2. **核心以独立可执行文件分发**：Xray 与 sing-box 作为 sidecar 进程（桌面）或官方/自建绑定（Android）调用，通过标准输入输出与配置文件交互，不把其源码合并进本项目源码树。分发时必须保留各自的许可证与声明文件。
3. **Android 若采用 AAR 绑定**：需单独核对绑定方式的许可影响，并作为新 ADR 记录。
4. **本项目自身许可证待用户选择**：在用户明确前，不引入任何 GPL 代码，保持可自由选择许可的空间。

## 待确认问题

| 问题 | 影响 | 需用户决定 |
|---|---|---|
| 本项目采用什么许可证？ | 决定能否复用 GPL 代码，以及分发义务 | 是 |
| Android 双核心是否接受 GPL 依赖？ | 决定 AAR 方案可行性 | 是 |

## 影响

- 正面：许可风险可控，不受第三方许可证传染。
- 负面：UI 与 VPN 服务实现需要从零编写，工作量大于直接移植。
- 缓解：参考项目仅作交互与结构参考，且 `src/references/` 不入库，天然降低了误复制风险。

3. 每个发布产物附许可证声明文件（NOTICE）。
