# 客户端选项集 / Client option set

面向：实现桌面端与 Android 界面的人。

参照物：[Clash Verge Rev](https://www.clashverge.dev/) 与 Clash for Android。
本文件把它们的选项集逐项映射到 sing-box 的配置字段上（内核选择见
[ADR-0005](../adr/ADR-0005-单内核-sing-box.md)）。

---

## 0. 三条原则

**① 两种模式共用同一份配置。**
简易模式是高级模式的**子集视图**，不是另一套配置。
各持一份的话很快就会出现「简单模式显示已连接、专业模式显示未连接」——
两个模式对同一件事给出不同答案，用户不知道该信哪个。

**② 每个选项都对应一个真实的 sing-box 字段。**
界面不提供「我们只是把它转成一个字符串」的伪选项。
伪选项的表现是：改了没反应，或者改了之后核心拒绝启动，
而错误信息来自核心深处，与用户的操作相距很远。

**③ 默认值必须能直接连上。**
用户不打开高级模式、不改任何一项，也应当能用。
因此默认值取「最安全且最可能可用」的那一档，而不是「最强大」的那一档。

---

## 1. 简易模式

只有一屏。目标是：**知道自己在连什么，并且能连上。**

| 区域 | 内容 |
|---|---|
| 状态 | 当前状态（未连接 / 连接中 / 已连接 / 需要修复）、当前节点名、本次连接时长 |
| 流量 | 上/下行速率与累计用量（来自订阅头的 `subscription-userinfo`） |
| 节点 | 节点列表，点击即切换；显示延迟；支持「自动选择最快」 |
| 连接 | 一个大按钮：连接 / 断开 |
| **路由模式** | 三选一：**规则** / **全局** / **直连**（默认「规则」） |
| **分应用代理** | Android：全部应用 / 排除所选 / 仅代理所选<br>桌面：不适用（系统代理与 TUN 都是全机的） |

**为什么简易模式只放这两个额外选项**

规则模式决定「什么走代理」，分应用代理决定「谁走代理」——
这两个是普通用户**真的会改**的。其余选项（DNS、TUN 栈、嗅探、规则集）
改错了的后果是「打不开网页」，而用户不会知道自己改了什么。

**「直连」要有明确提示。** 选了直连就是全部不走代理，
表现是「连上了但打不开墙外网站」。这不是 bug，需要在选中时用一行小字说明。

## 2. 高级模式

参照 Clash Verge 的分组。下列每一项都标注了对应的 sing-box 字段。

### 2.1 代理 / Proxies

| 选项 | 取值 | 默认 | sing-box |
|---|---|---|---|
| 节点列表 | 来自订阅 | — | `outbounds[]` |
| 节点延迟测试 | 测试 / 单节点重测 | — | 通过本地 API 或直接拨号 |
| 延迟测试地址 | URL | `https://www.gstatic.com/generate_204` | — |
| 延迟测试超时 | 毫秒 | 5000 | — |
| **代理组** | 见下 | 一个「手动选择」+ 一个「自动选择」 | `outbounds[type=selector/urltest]` |

**代理组类型**（对应 `proxy-groups`）：

| 类型 | 含义 | sing-box |
|---|---|---|
| 手动选择 | 用户选定一个 | `selector` |
| 自动选择 | 延迟最低的 | `urltest` |
| 故障转移 | 第一个可用的 | `selector` + 健康检查 |
| 负载均衡 | 轮询 | `selector`（sing-box 的等价能力有限，见「已知差异」） |

每个代理组可配：成员列表、是否包含全部节点（`include-all`）、
测试地址、测试间隔、失败次数上限。

### 2.2 规则 / Rules

| 选项 | 取值 | 默认 | sing-box |
|---|---|---|---|
| **路由模式** | 规则 / 全局 / 直连 | 规则 | `route.final` + 规则集合 |
| 规则列表 | 可增删排序 | 内置一套 | `route.rules[]` |
| 规则类型 | 域名 / 域名后缀 / 域名关键字 / IP-CIDR / 进程名 / GEOSITE / GEOIP / 端口 | — | `domain`、`domain_suffix`、`domain_keyword`、`ip_cidr`、`process_name`、`rule_set`、`port` |
| 规则动作 | 走代理 / 直连 / 拒绝 / 指定代理组 | 走代理 | `outbound` / `action` |
| **规则集** | 内置 + 远程更新 | 内置一份 | `route.rule_set`（`type: local` 或 `remote`） |
| 规则集更新间隔 | 小时 | 24 | `rule_set.update_interval` |
| 兜底规则 | 走代理 / 直连 | 走代理 | `route.final` |

**兜底默认是「走代理」而不是「直连」。**
回落直连会在规则没覆盖到时**静默泄漏真实流量**——
用户以为在走代理，实际上没有。宁可多走一点代理。

**规则排序即优先级**，界面必须支持拖动排序并显示序号。
顺序错了后果是「某条规则永远不生效」，而用户看不出是顺序问题。

### 2.3 DNS

| 选项 | 取值 | 默认 | sing-box |
|---|---|---|---|
| 启用 DNS 覆写 | 开 / 关 | 开（规则模式下） | `dns.servers` |
| **增强模式** | fake-ip / 正常 | fake-ip | `dns.fakeip` |
| fake-ip 网段 | CIDR | `198.18.0.1/16` | `dns.fakeip.inet4_range` |
| 名称服务器 | 列表 | 两个 DoH + 一个明文 | `dns.servers[]` |
| 国内/国外分流解析 | 开 / 关 | 开 | `dns.rules[]` |
| fake-ip 过滤 | 列表 | 内置（局域网、NTP、微信、QQ 等） | `dns.rules[]` |
| 使用 hosts | 开 / 关 | 开 | `dns.servers[type=hosts]` |
| IPv6 解析 | 开 / 关 | 关 | `dns.strategy` |

**IPv6 默认关。** 多数代理链路对 IPv6 支持不完整，
开着会表现为「某些网站慢或超时」，而用户很难联想到 IPv6。

### 2.4 流量接入 / Inbound

| 选项 | 取值 | 默认 | sing-box |
|---|---|---|---|
| **接入方式** | 系统代理 / TUN / 仅本地端口 | 系统代理（桌面）<br>TUN（Android） | 见下 |
| 混合端口 | 端口号 | 7890 | `inbounds[type=mixed]` |
| 允许局域网连接 | 开 / 关 | 关 | `inbounds[].listen` 设为 `0.0.0.0` |
| **TUN 栈** | system / gvisor / mixed | mixed | `inbounds[type=tun].stack` |
| TUN 设备名 | 字符串 | 按平台默认 | `...device` |
| MTU | 数字 | 1500 | `...mtu` |
| 自动路由 | 开 / 关 | 开 | `...auto_route` |
| 严格路由 | 开 / 关 | 关 | `...strict_route` |
| DNS 劫持 | 列表 | `any:53` | `...dns_hijack` |

**「允许局域网连接」默认关，且开启时要有明确警告。**
开启后同一网络下的任何人都能用这个代理——
在公共 Wi-Fi 下等于把自己的流量出口分享出去。

**Android 的分应用代理**（TUN 入站）：

| 模式 | 含义 | sing-box |
|---|---|---|
| 全部应用 | 不设过滤 | 无 `include/exclude_package` |
| 排除所选 | 所选应用**不**走代理 | `exclude_package` |
| 仅代理所选 | 只有所选应用走代理 | `include_package` |

### 2.5 嗅探 / Sniffing

| 选项 | 默认 | sing-box |
|---|---|---|
| 启用嗅探 | 开（TUN 模式下） | `inbounds[].sniff` |
| 嗅探协议 | TLS / HTTP / QUIC | 同上 |
| 覆写目的地址 | 关 | `route.rules[].action: sniff` |

覆写默认关：它会让连接的实际目的地与用户看到的域名不一致，
排查问题时容易误判。

### 2.6 订阅 / Profiles

| 选项 | 默认 | 说明 |
|---|---|---|
| 订阅地址 | 来自面板 | 也可手工填写 |
| 自动更新 | 开 | |
| 更新间隔 | 6 小时 | |
| 更新时走代理 | 开 | 面板本身可能需要代理才能访问 |
| 节点名前缀 | 空 | 多订阅合并时用于区分 |

### 2.7 应用 / App

| 选项 | 默认 | 说明 |
|---|---|---|
| 开机自启 | 关 | 打开软件不等于接管网络，但用户往往这么以为 |
| 启动时最小化到托盘 | 关 | |
| 启动后自动连接 | 关 | |
| 语言 | 跟随系统 | |
| 主题 | 跟随系统 | |
| 日志等级 | warning | `log.level`：trace/debug/info/warn/error |
| 日志保留行数 | 1000 | 界面内保留，不写盘 |

## 3. 已知差异（必须如实标注）

参照物是 mihomo，本项目是 sing-box，两者能力**不完全等价**。
以下差异必须写进界面，而不是假装一致：

| 项目 | mihomo | sing-box | 处理 |
|---|---|---|---|
| 负载均衡组 | `load-balance` 一等公民 | 无直接等价 | 提供「轮询」近似实现，并注明**不保证会话保持** |
| 规则集格式 | `.mrs` / `.yaml` | `.srs` / 源 JSON | 只接受 sing-box 的格式；混用会加载失败 |
| 进程名规则 | `process-name` | `process_name`，且平台支持不同 | 桌面端可用，**Android 不可用**（系统不允许按包名匹配进程） |
| TUN 栈 | 三种 | `system`/`gvisor`/`mixed` | 一致 |
| 入站 SOCKS/HTTP 分端口 | 分开 | `mixed` 一个端口 | 只提供混合端口 |

**Android 的进程名规则不可用**这一条尤其要在界面上说明：
参照对象提供了这个选项，用户会去找，而它在 Android 上根本不可能生效。

## 4. 两种模式的对应关系

| 高级模式中的选项 | 在简易模式中 |
|---|---|
| 路由模式 | 直接暴露（三选一） |
| 分应用代理（Android） | 直接暴露 |
| 节点列表与自动选择 | 直接暴露（简化为一个列表 + 「自动选择最快」） |
| 代理组 | 隐藏，使用默认的两个组 |
| 规则列表 / 规则集 | 隐藏，使用内置规则集 |
| DNS | 隐藏，使用默认值 |
| TUN 栈 / MTU / 路由 | 隐藏，使用默认值 |
| 嗅探 | 隐藏，使用默认值 |
| 订阅 / 应用 / 日志 | 隐藏，使用默认值 |

**隐藏不等于不可用**：简易模式下这些选项仍然按默认值生效，
切换到高级模式后能看到并修改它们。
