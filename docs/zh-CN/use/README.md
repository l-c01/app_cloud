# 使用说明 / User guide

面向：使用本客户端的普通用户。

> **当前状态：本版本尚未经过真机验证，请勿用于日常使用。**
> 哪些部分可用、哪些还不可用，见文末的「这一版能做什么」。

---

## 1. 它是什么

一个 Xboard 面板的代理客户端。它是**客户端**，不提供任何代理服务本身——
你需要有自己的面板账号或订阅链接。

与常见客户端的区别：

- **单内核（sing-box）**：内核随程序分发，不需要你另外安装。
- **两种界面模式**：简单模式只有「连接/断开」；专业模式展开全部选项。
  切换模式**不会**改变已经建立的行为。
- **界面语言跟随系统**，也可以在设置里指定。

---

## 2. 第一次使用

### 2.1 获取订阅链接

有两种方式，任选其一：

**方式 A：从面板获取（需要账号）**

1. 打开「设置」→ 填写面板地址
2. 用邮箱与密码登录
3. 登录后自动取得你的订阅链接

面板地址由你自己提供，本软件**不预置任何面板地址**。
这不只是隐私选择：预置地址意味着所有人的流量都指向同一个地方。

**方式 B：手动填写订阅链接**

如果你已经有订阅链接（例如从其它客户端导出），直接粘贴即可。

> **订阅链接是凭据。** 拿到它的人就能使用你的账号流量。
> 不要把它发到聊天群、截图或粘贴到不受信任的网站。
> 本软件在日志与诊断信息里会自动把它替换成 `<redacted>`。

### 2.2 选择接入方式

| 方式 | 适用 | 说明 |
|---|---|---|
| **系统代理**（桌面默认） | 大多数情况 | 只影响读取系统代理设置的应用 |
| **TUN 虚拟网卡** | 需要接管全部流量时 | 通常需要管理员权限 |
| **PAC 自动配置** | 想按规则决定哪些走代理 | 规则由本地服务提供 |
| **仅本地端口** | 自己配置其它软件 | 不改动任何系统设置 |
| **VPN**（Android） | Android 唯一方式 | 系统会弹出授权对话框 |

**系统代理不等于全部流量。** 不遵循系统代理设置的应用不会经过代理——
它可能仍然直连。这不是 bug，是这类接管方式的固有边界。
TUN / VPN 才能接管全部流量。

## 3. 界面说明

### 简单模式

只有三样东西：当前状态、当前节点、连接按钮。

刻意**不显示**路由策略、接入方式与日志。这些不是被隐藏的高级功能，
而是会让人做错决定的选项：一个不懂分流规则的用户选了「全局直连」，
表现就是「连上了但打不开网页」，而他不会知道原因。

### 专业模式

展开全部三个维度：

- **流量接入方式**：见上表
- **路由策略**：规则分流 / 全局代理 / 全局直连
- **节点列表**

内核不需要选：本构建只提供 sing-box 一个内核。

## 4. 出问题时

### 连上了但打不开网页

按顺序检查：

1. **接入方式选对了吗？** 如果选了「全局直连」，那所有流量都直连，
   打不开墙外的网站是正常的。
2. **是不是「系统代理」但应用不读它？** 换 TUN 试试。
3. **节点本身可用吗？** 换一个节点。
4. **看日志**（专业模式）：核心的输出会显示在这里，
   凭据已自动过滤。

### 断开之后完全没网

这意味着系统网络设置没有恢复到你的原始值。

专业模式里查看「网络需要修复」状态。程序会列出**具体哪个设置项**
与预期不一致，以及它当前的实际值。**它不会自动覆盖**——因为那个值
很可能是你自己改的，覆盖等于抹掉你的修改。

### 提示「后台服务未运行」

桌面客户端的界面与真正做事的服务是两个进程。服务没启动时，
界面能打开但无法控制代理。

### 提示「网络设置冲突」

你在使用期间（或程序运行期间）手工改了某个系统网络设置，
程序检测到它与本次连接写入的值不一致，因此**没有动它**。

这是刻意的：自动覆盖会抹掉你的修改，而且你不知道是谁干的。

## 5. 隐私

| 项目 | 处理方式 |
|---|---|
| 订阅链接、会话凭据 | 按凭据处理：不入日志、不入导出、不入诊断包 |
| 云端备份 | **关闭**，且显式排除全部数据域 |
| 面板地址 | 源码里**不带任何生产地址**，全部由你填写 |
| 崩溃报告 | 不发送 |
| 核心二进制 | 只从官方 Release 下载，并校验 SHA256 |

Android 上 `allowBackup=false`：换机时请重新登录，
而不是让凭据被静默复制到你可能并未意识到的地方。

## 6. 这一版能做什么

**如实说明**（这一点比功能列表更重要）：

| 功能 | 状态 |
|---|---|
| 面板登录、取得订阅链接 | 代码已写，**未编译验证** |
| 订阅拉取与节点解析 | 代码已写，**未编译验证** |
| sing-box 配置编译 | 代码已写，**未编译验证**；能力表**未针对锁定版本实测** |
| 桌面界面（两种模式） | 代码已写，**未编译验证** |
| Android 界面 | 代码已写，**未编译验证** |
| Android 接管流量 | **未实现**：APK 能装、能开界面、能建 VPN，但不代理流量 |
| 应用内核心更新 | **未实现** |
| 真机运行验证 | **完全没有做过** |

「未编译验证」的意思是：这些代码在本机从未被编译器看过一遍。
所有编译与测试都在 GitHub Actions 里进行，结果以那里为准。
