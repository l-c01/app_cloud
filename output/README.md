# output/ — 对外输出目录

本目录存放对外的产物与证据。**`reports/` 纳入版本管理**（属证据），`builds/` 与 `exports/` 体积大且可再生成，不进版本历史。

## 子目录

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `builds/` | 各目标架构的构建产物（zip、安装包、APK、deb、OCI 镜像导出）与 SHA256 校验和 | 否 |
| `reports/` | 验证报告、审计结论、性能基线、能力矩阵快照 | **是** |
| `exports/` | 交付归档、给用户的导出包、脱敏诊断包 | 否 |

> `reports/` 是阶段关卡的证据归档，必须保留并随仓库一起版本化。

## 命名规范

```
<用途>-<版本>-<目标>-<日期>.<扩展名>
```

示例：

- `builds/proxyclient-0.1.0-windows-amd64-20261014.zip`
- `reports/report-G0-0.1.0-all-20261014.md`
- `exports/handover-0.1.0-20261014.zip`

## 规则

1. 产物必须可追溯到具体版本与目标；文件名缺版本或缺目标视为不合规。
2. 构建产物同时输出 SHA256 校验和文件（`*.sha256`）。
3. 报告中的「未运行」检查必须显式标为 `not_run`，不得省略或写成通过。
4. 秘密（token、密码、签名私钥、订阅链接）绝不进入本目录；导出前必须脱敏。
