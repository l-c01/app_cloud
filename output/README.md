# output/ — 对外输出目录

本目录存放**可再生成的对外产物**，不纳入 git 版本历史（`.gitignore` 已排除，仅保留本说明文件）。

## 子目录

| 目录 | 内容 |
|---|---|
| `builds/` | 各目标架构的构建产物（zip、安装包、APK、deb、OCI 镜像导出）与 SHA256 校验和 |
| `reports/` | 验证报告、审计结论、性能基线、能力矩阵快照 |
| `exports/` | 交付归档、给用户的导出包、脱敏诊断包 |

## 命名规范

```
<用途>-<版本>-<目标>-<日期>.<扩展名>
```

示例：

- `builds/proxyclient-0.1.0-windows-amd64-20261014.zip`
- `reports/report-0.1.0-windows-amd64-20261014.md`
- `exports/handover-0.1.0-20261014.zip`

## 规则

1. 产物必须可追溯到具体版本与目标；文件名缺版本或缺目标视为不合规。
2. 每个产物同时输出 SHA256 校验和文件（`*.sha256`）。
3. 报告中的「未运行」检查必须显式标为 `not_run`，不得省略或写成通过。
4. 秘密（token、密码、签名私钥、订阅链接）绝不进入本目录；导出前必须脱敏。
